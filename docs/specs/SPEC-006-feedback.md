# SPEC-006 — 演出（画面の切り替え・GUM の手ごたえ・Lv・クリア）

| 項目 | 内容 |
|---|---|
| 状態 | Done |
| 関連 | bearko/MyCryptoPortfolio の ROADMAP 3 章（演出）、SPEC-005（演出を減らす）。先例：Survivor SPEC-045・Tactics SPEC-013 |

## 1. 背景

画面（モーダル）はパッと出て消えるだけで、GUM が増えても数字が置き換わるだけだった。いちばん大きい報酬である工房 Lv とクリアにも手ごたえがなかった。

## 2. 仕様

| 何に | 演出 | 長さ |
|---|---|---|
| 全画面のモーダル・各ビュー | ふわっと出る（不透明度） | 0.2 秒 |
| モーダルのカード・メニュー | 少し下から浮き上がる | 0.24 秒 |
| GUM が増えた | ヘッダーの数字をカウントアップし、数字がはずむ。横に「+N」が浮いて消える | 0.6 秒（+N は 0.85 秒） |
| GUM が減った（支払い） | すぐに変える（演出なし） | — |
| 工房 Lv が上がった | ヘッダーの Lv が光ってはずむ | 0.8 秒 |
| クリア画面 | 紙吹雪（60 枚・2.6 秒。タップを止めない）・カードが大きめに浮き上がる | 0.45 秒 |

- **遊びを止めない**：どれも操作を待たせない（紙吹雪は `pointer-events: none`）。「+N」は同時に 1 つだけ
- **演出を減らす**（SPEC-005）とき：CSS のアニメはほぼ 0、GUM はすぐ変わり「+N」と紙吹雪は出さない
- セーブから読み込んだときの GUM はカウントアップしない

## 3. 受け入れ基準

- [ ] GUM が増えるとカウントアップと「+N」、減るとすぐ変わる
- [ ] 工房 Lv が上がるとヘッダーの Lv が光る。クリアで紙吹雪
- [ ] 演出を減らすと、どれも出ない（値はすぐ正しくなる）

## 4. テスト

- Playwright（`?debug=1`、`reducedMotion` あり／なし）：`addGum(1234)` の 0.12 秒後に途中の値と「+1,234」、0.9 秒後に最終値。`addGum(-500)` はすぐ。`setLevel(5)` で紙吹雪の数
