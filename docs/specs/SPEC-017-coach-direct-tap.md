# SPEC-017 — マイのセリフ中でも、光っているボタンを直接押せる

| 項目 | 内容 |
|---|---|
| 状態 | Done |
| 関連 | SPEC-007（指差し）、SPEC-016（MENU を光らせる時機）。作者の指摘 2026-10-18 |

## 1. 背景

マイのセリフは画面全体に透明な重ね（`.mai-modal`、z=280）を敷き、どこを押しても「次へ」になる。ほかの UI を押せないのは適切だが、**マイが「光っている MENU から」と言っているのに、その MENU を押してもセリフが閉じるだけ**で、もう一度押さないとメニューが開かなかった。

## 2. 仕様

- マイのセリフ中に光らせているボタン（いまはホームのチュートリアルの最後の行の MENU）の上に、重ねより上（z=285）の透明な当たり判定 `#coachHit` を置く
- それを押すと、**セリフを最後まで送って閉じ**（閉じたあとの処理も、閉じるボタンと同じに走る）、**そのボタンを押したのと同じ**にする。MENU ならメニューが開き、次はクラフトが光る
- 光っていないところを押したときは今までどおり（セリフが進む・閉じるだけ）。ほかの UI は押せないまま
- 見た目はボタン側の光（SPEC-007 の輪）のまま。当たり判定は画面の大きさ・スクロールに合わせて置き直す
- 時間の止め方は変えない（セリフを閉じて `resumeTime`、メニューを開いて `pauseTime`）

## 3. 受け入れ基準

- [ ] 「まずは光っている MENU から」の行で MENU を押すと、1 回でメニューが開く
- [ ] 1 行目（MENU がまだ光っていない）で MENU の場所を押すと、セリフが進むだけ
- [ ] MENU 以外を押すとセリフが閉じるだけで、MENU は光り続ける

## 4. テスト

- Playwright（390×844・360×640）：1 行目で MENU の場所 → 2 行目へ／2 行目で MENU → セリフが閉じてメニューが開き、クラフトが光る（pauseFlags 1）→ 新規開発が光る → 閉じると pauseFlags 0／2 行目で別の場所 → 閉じるだけ
