## 1. 背景

ホームのマーケットの欄に「オークション」の枠があり（注目度・人気は「—」）、押すとマイが「まだ準備中です」と言うだけになっている（`menu.auction.todo`）。ポータルの紹介文は「マーケットやオークションで売って GUM を稼ぎます」。作者の決定で、今回の仕上げで作る。

いまの出品（マーケット）は「確実に売れる」もの：相場の 85%（1 週）・100%（4 週）・120%（8 週）から選び、手数料 10%、値段の揺れは ±10%。

## 2. 目標 / 非目標

- **目標**：マーケットと役割が重ならないオークションを作る。**月に 1 回の開催で、出来のよい品ほど高く売れる。そのかわり入札がなくて売れないことがある**
- **非目標**：ヒーローの売買、ほかのプレイヤーとの入札（オンライン）、入札の駆け引きをプレイヤーが操作すること（入札は自動）

## 3. 仕様

### 3.1 開催と出品

- **毎月 4 週目の終わりに開催**（落札が決まる）。いままでの枠の「開催まで n 週」（`computeAuctionWeeksRemaining`）をそのまま使う
- 出品は **1 回の開催に 1 品**。倉庫の品で、マーケットに出品中でないもの
- **担当ヒーロー**を 1 名選ぶ。条件はマーケットの出品と同じ（待機中で、品と同じレアリティ以上か「商」。`canSellExt`）。担当は開催まで拘束される（クラフト・クエスト・出品に出せない）
- **出品料 100 GUM**（出品したときに払う。売れなくても戻らない）。落札したときは、マーケットと同じ手数料 10% を引く
- 出品の取り消しはできない
- 開催の週（4 週目）に出品したときも、その月の終わりに開催する（待ちは短いが、3.2 の「開催までの日数」の点が付かない）

### 3.2 注目度（0〜100）

品の出来と担当で決まる。出品の画面で、決まる前から内訳を見せる。

| もと | 点 |
|---|---|
| 査定 | 凡作 0・並 10・良作 20・秀作 35・傑作 50 |
| レアリティ | Common 0・Uncommon 5・Rare 10・Epic 15・Legendary 20 |
| 担当が「商」 | +15 |
| 今月の人気シリーズ（3.3） | +15 |

- 合計は 100 で止める

### 3.3 人気（今月の人気シリーズ）

- **毎月 1 週目に、クラフトできるシリーズ（`unlockedSeries`）の中から 3 つ**を「今月の人気」に選ぶ。出品の画面とホームの枠に出す
- 出品した品のシリーズがその 3 つに入っていれば、注目度 +15

### 3.4 落札

開催のときに 1 回だけ決める（セーブ・ロードで結果は変わらない：出品のときに乱数の種を決めて持っておく）。

- **入札の数** ＝ 注目度 ÷ 15（切り捨て）＋ 0〜2 の乱数
  - **0 件なら不成立**。品は倉庫に戻り、出品料は戻らない
- **落札額** ＝ 基準価格 ×（0.8 ＋ 注目度 ÷ 100）× 揺れ（0.9〜1.1）
  - 基準価格は、マーケットの「相場に合わせる」と同じ（レアリティ × 査定。`estimateSalePrice(…, 'standard', null)`。「商」の +10% は注目度のほうに入れるので、ここでは掛けない）
  - 手取りは手数料 10% を引いたもの
- 目安：
  | 品 | 注目度 | 落札額の倍率（基準価格に対して） | 入札 0 件の確率 |
  |---|---|---|---|
  | 良作の Rare・担当は商でない | 30 | 約 1.1 倍 | 0（2 件以上） |
  | 凡作の Common・担当は商でない | 0 | 約 0.8 倍 | 3 回に 1 回 |
  | 傑作の Legendary・商・人気シリーズ | 100 | 約 1.8 倍 | 0 |
  - マーケットの「価格重視」（8 週で 1.2 倍）より速く、出来のよい品ほど上を狙える。出来の悪い品はマーケットのほうが得

### 3.5 結果の知らせ方

- **時間を止めない**。マーケットの成約と同じく、画面上部の速報タイル（`state.notifications`）と効果音
  - 落札：「[品名] が [入札 n 件] で落札！ [手取り] GUM」
  - 不成立：「[品名] は入札がありませんでした。倉庫に戻しました」
- 落札は、工房 Lv の条件の「売却数」（`saleCompletedCount`）に数える。マーケットの売却と同じく、6% で未取得のシリーズのレシピを得る

### 3.6 画面

- **マーケット画面に「オークション」タブ**（倉庫・雇用・出品の隣）。
  - 開催まで n 週・今月の人気シリーズ 3 つ・出品料
  - 品を選ぶ → 担当を選ぶ → 注目度の内訳・入札の見込み（「n〜n+2 件」）・落札額の目安（下限〜上限の GUM） → 「出品する」
  - 出品中は、その品・担当・注目度・開催まで n 週を出す
- **ホームの枠**（いまの「—」）：出品中なら品名・注目度・人気シリーズなら ★・開催まで n 週。出品していなければ、いままでどおり「オークションに出品」のボタン（押すとマーケット画面のオークションタブを開く）
- `menu.auction.todo`（準備中）は使わなくなるので消す
- マーケットのヘルプ（`mai-help.js` の `market`）を、倉庫・出品・雇用・オークションのいまの中身に書き直す。出品・オークションの担当の決まり（品と同じレアリティ以上か「商」）もここに書く
- 文言は `data/i18n/ui.json`（ja / en）

### 3.7 state とセーブ

- `state.activeAuction`：`{ warehouseIdx, sellerId, listedAtWeek, closeWeek, attention, popular, seed }` か `null`
- `state.auctionPopular`：`{ month: 通算の月, series: [3 つ] }`
- どちらもセーブに入れる（一時的なものではない）。前のセーブには無いので、既定値（`null`）のまま読める。`SAVE_VERSION` は上げない
- 品の番号（`warehouseIdx`）は、マーケットの売却で倉庫から品が消えたときにずれるので、マーケットと同じく補正する

### 3.8 純関数とテスト

`js/factory-market.js` に DOM に触れない関数として置き、`tests/auction.test.mjs`（`node:test`）で試す。

- `auctionAttention({ tier, rarity, sho, popular })` → `{ total, parts }`
- `auctionBidders(attention, rng)`、`auctionHammerPrice(base, attention, rng)`、`pickPopularSeries(series, rng)`
- 種から決まる乱数（`seededRng(seed)`）で、同じ種なら同じ結果

### 3.9 釣り合いの確かめ

- `tools/sim/` に、マーケットの 3 つの速さとオークションの「1 週あたりの手取り」を、査定・レアリティごとに比べる表を出すスクリプトを足す
- 自動プレイ（8 年）で、オークションを使っても工房 Lv.5 までの週数が大きく縮まない（総合スコアの基準 `TYPICAL_WEEKS_TO_LV5` = 240 週が崩れない）ことを確かめる

## 4. 受け入れ基準

- [ ] マーケット画面にオークションのタブがあり、品と担当を選んで出品できる（出品料 100 GUM）
- [ ] 毎月 4 週目の終わりに落札か不成立が決まり、速報タイルで知らされる。時間は止まらない
- [ ] 注目度の内訳・今月の人気シリーズ・入札の見込み・落札額の目安が、出品の前に見える
- [ ] ホームの枠に出品中の品・注目度・開催まで n 週が出る。「準備中」は出ない
- [ ] セーブして読み直しても、出品中のオークションと結果が変わらない
- [ ] 英語表示で英語の文言になる
- [ ] `node --test` が通る。自動プレイで工房 Lv.5 までの週数が大きく変わらない
