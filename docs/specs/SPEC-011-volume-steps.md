# SPEC-011 — 音量の 20 段階（BGM・効果音）

| 項目 | 内容 |
|---|---|
| 状態 | Done（作者の依頼 2026-10-17「BGM/SE の音量を全タイトルで 20 段階で設定できるようにしたい」） |
| 関連 | SPEC-005（設定）。先例：Survivor SPEC-044（`index.html` の音量スライダー・`settings.js` の `mixVolume`） |

## 1. 背景

SPEC-005 で BGM・効果音の音量スライダー（0〜100・5 刻み）を入れたが、いまの値が画面に出ない。
つまみの位置だけでは「いま何段階か」「左端で OFF になるのか」が分からず、保存する値も 5% 刻みに
そろえていなかった。全タイトル（Survivor・Fortress・Factory）で同じ 20 段階にそろえる。

## 2. 仕様

### 2.1 画面（メニュー →「設定」）

| 項目 | 内容 |
|---|---|
| つまみ | `<input type="range" min="0" max="100" step="5">`（いままでどおり）。0・5・…・100 の 21 の位置。0 は OFF、ほかが 20 段階 |
| 表示 | つまみの右に、いまの段階を出す。0 は「OFF」（`settings.off`。言語で変わる）、ほかは「65%」 |
| 動かしたとき | 表示と音量をその場で反映する（`input`）。効果音は動かし終えたとき（`change`）にボタンの音を 1 回鳴らして確かめる（いままでどおり） |
| 既定 | 100%（いままでの大きさ） |

- 最終的な音量は、既定の音量（BGM 0.32・効果音 0.55、効果音ごとの個別値）× 設定（0〜1）。SPEC-005 のまま
- BGM の音量は再生中の BGM にその場で反映する（`setBgmVolume`）。0 にすると止まり、戻すと再開する
- ON / OFF のボタンは残す。OFF のときはつまみを押せなくする（SPEC-005）

### 2.2 保存

- `mcf.settings` の `bgmVolume` / `seVolume`（0..1）はそのまま。読むとき・変えたときに **5% 刻みに丸める**
  （0.37 → 0.35。範囲外は 0..1 に収める。数でなければ既定の 1）
- 保存の形は変わらないので、いまの設定はそのまま使える

### 2.3 純ロジック（`js/factory-settings.js`）

| 名前 | 中身 |
|---|---|
| `snapVolume(v, d)` | 0..1 を 5% 刻みに丸める。数でなければ `d` |
| `volumeLabel(v, off)` | 画面に出す文字。0 は `off`、ほかは `"65%"` |
| `normalizeSettings` | 音量に `snapVolume` を通す（読むとき・書くとき・`pickSetting`） |

## 3. 受け入れ基準

- [ ] 設定のつまみの右に「100%」が出て、動かすとその場で変わる。左端まで下げると「OFF」
- [ ] 効果音のつまみを放すと、その大きさでボタンの音が 1 回鳴る。BGM は動かしている間に大きさが変わる
- [ ] 再読み込みしても段階が残る。「はじめから」でも消えない（SPEC-005）
- [ ] 360×640 で設定が画面に収まる（つまみと表示が重ならない）

## 4. テスト

- `node --test tests/settings.test.mjs`：`snapVolume` の丸めと範囲、`normalizeSettings` が音量を丸めること、`volumeLabel`
- ブラウザ：設定を開いて動かす。音が鳴るかはサンドボックスでは確かめられない（作者の確認）
