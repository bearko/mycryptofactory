# SPEC-020 — 画面ごとのチュートリアルでも、次に押すボタンを光らせて直接押せる

| 項目 | 内容 |
|---|---|
| 状態 | Done |
| 関連 | SPEC-007（指差し）、SPEC-016（MENU を光らせる時機）、SPEC-017（光っているボタンを直接押せる）。作者の依頼 2026-10-18（「同じように他の画面も」） |

## 1. 背景

SPEC-017 で、ホームのチュートリアルの MENU だけは、マイのセリフ中でも直接押せるようにした。クラフト・ヒーローの画面のチュートリアルも「〜を押しましょう」と言うのに、どこを押すかは光らず、セリフを送り切らないと押せなかった。

## 2. 仕様

### 2.1 光らせるボタン（チュートリアルの最後の行で）

| チュートリアル | 光らせるもの | 押したあとに続けて光らせるもの |
|---|---|---|
| クラフト選択（`craftSelect`） | 作れるエクステンションの先頭の行 | — （確認画面のチュートリアルに続く） |
| クラフト確認・未編成（`craftConfirmNoTeam`） | 空いている「+」の枠（なければ「変更」） | — （ヒーロー画面のチュートリアルに続く） |
| クラフト確認・編成済み（`craftConfirmWithTeam`） | 「クラフト開始」 | — |
| ヒーロー画面（`heroTeam`） | 編成が空なら選べるヒーローの先頭、編成済みなら「戻る」 | ヒーロー → 「戻る」 → 確認画面の「クラフト開始」 |
| クラフト中（`craftInProgress`） | なし（見ているだけで済む） | — |
| ランドの通行証（`landFirstFree`） | なし（どのランドを選ぶかは本人が決める。先頭を光らせると選び方を誘導してしまう） | — |

- 最後の行のあいだは、SPEC-017 と同じ当たり判定をマイの重ねの上に置き、押すと**セリフを閉じてそのボタンを押したのと同じ**にする
- セリフを閉じても、押すまで光らせておく（画面が描き直されて消えたら、それまで）。押したら光を消し、「続けて光らせるもの」があれば少し待って光らせる
- 光らせるボタンが画面の外にあれば、見える位置までスクロールする
- 光の見た目と「演出を減らす」での扱いは SPEC-007 のまま

### 2.2 画面を開いたまま出すセリフで、時間が進んでいた（直したもの）

マイのセリフは閉じるときに必ず `resumeTime` を 1 回呼ぶ。クラフト・ヒーロー画面を開いたまま出すチュートリアルでは、その 1 回が**画面の pause を消費**してしまい、セリフを閉じた時点で画面を開いたまま時間が進んでいた。チュートリアルを出す前に、すでに止まっているなら `pauseTime` を 1 回足す（`holdPauseForMai`）。ホームのチュートリアル（止まっていない状態で出す）は今までどおり。

## 3. 受け入れ基準

- [ ] 最初のクラフトまで、光っているボタンを押すだけで進める（MENU → クラフト → 新規開発 → エクステンション → 「+」→ ヒーロー → 「戻る」→「クラフト開始」）
- [ ] 各チュートリアルの 1 行目では光らず、セリフが進むだけ
- [ ] クラフト・ヒーロー画面を開いているあいだは時間が止まっている（pauseFlags 1）。ホームに戻ると 0

## 4. テスト

- Playwright（390×844・360×640、`?debug=1`）：タイトル →「はじめから」から、各チュートリアルの 1 行目だけ送り、あとは光っているものだけを押して、クラフトが始まるところまで。各段階の光っているもの・当たり判定・pauseFlags を記録
