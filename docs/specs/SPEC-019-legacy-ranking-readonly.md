## 1. 背景

本作には前からのランキング（Google Apps Script。`js/factory-ranking-client.js`）と、bearko.games 共通基盤の総合ランキングの 2 つがある。SPEC-010 で総合ランキングへのリンクを置いたが、遊ぶ人には 2 つの違いが分かりにくい。作者の決定で、**新しい記録は旧ランキングに送らず、見るだけ残す**。🏆 は総合ランキングを主にする。

## 2. 目標 / 非目標

- **目標**：記録が載るのは bearko.games の総合ランキングだけにする。旧ランキングは「旧ランキング」として、これまでの記録を見られるまま残す
- **非目標**：旧ランキングの記録を共通基盤へ移すこと、GAS のスプレッドシートを消すこと

## 3. 仕様

### 3.1 ランキングの窓（🏆。タイトル・ヘッダー・成績の画面から開く `#rankingViewer`）

- いちばん上に **「bearko.games のランキングを見る ↗」** のボタン（`https://bearko.games/score/?game=factory`。新しいタブ。再読み込みすると RTA の計測が消えるため。SPEC-010 と同じ）と、添え書き「Factory の記録は bearko.games のランキングに載ります。ランキングに名前を出すには、bearko.games でログインしてください」（未ログインの記録は仮アカウントに貯まり、ランキングには出ない。共通基盤 SPEC-001 4.6）
- その下に見出し **「旧ランキング（2026/10/18 までの記録）」** と、いままでの一覧（取得・最新を取得はいままでどおり。SPEC-013 の表示の決まりもそのまま）
- **上級設定（別のランキングサーバーの URL）は外す**。新しい記録を送らないので要らない。読むときは既定の URL（localStorage `mcf.rankingApiUrl` に入っていればそれ）をそのまま使う

### 3.2 成績の画面（8 年の終わり・ゲームオーバーのあと `#rankingScoreView`）

- **プレイヤー名の欄と「ランキングに登録」を外す**。代わりに「この記録は bearko.games のランキングに載ります」と「🏆 ランキングを見る」（3.1 の窓）
- 成績（スコアと内訳）・「活動レポートを見る」はいままでどおり

### 3.3 コード

- `submitRankingNow` と送信のボタンの処理を消す。`factory-ranking-client.js` の送信の関数（`submitFactoryScore`）は使わなくなるので消し、読む関数だけ残す
- localStorage の `mcf.playerName` は使わなくなる（残っていても害はないので消しには行かない）。CLAUDE.md の localStorage の一覧を直す
- 文言は `data/i18n/ui.json`（ja / en）。使わなくなったキー（`ranking.playerName`・`ranking.submitBtn` など）は消す

## 4. 受け入れ基準

- [ ] 🏆 の窓のいちばん上に「bearko.games のランキングを見る ↗」があり、新しいタブで Factory のランキングが開く
- [ ] 窓の下に「旧ランキング（2026/10/18 までの記録）」として、これまでの一覧が出る
- [ ] 成績の画面に名前の欄と登録のボタンが無い
- [ ] 英語表示で英語の文言になる
- [ ] `node --check`・`node --test` が通る
