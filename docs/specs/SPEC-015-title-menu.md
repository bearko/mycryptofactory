# SPEC-015 — タイトル画面をボタン式にする（はじめから・つづきから・RTA・設定）

| 項目 | 内容 |
|---|---|
| 状態 | Done |
| 関連 | SPEC-002（セーブ）、SPEC-003（RTA）、SPEC-005（設定）、SPEC-007（ヘルプ）、SPEC-012（全体チャット）。先例：DeckBattle のタイトル（つづきから・はじめる・遊び方） |

## 1. 背景（作者の指摘 2026-10-18）

- セーブがないとき、タイトルは「PRESS TO START」（画面のどこを押しても始まる）と「⏱ RTA で始める」（ボタン）が並び、始め方の見た目がそろっていなかった。ほかのタイトルは「はじめから」「つづきから」などのボタンで始める
- **画面全体が当たり判定**だったので、共通基盤の全体チャットのアイコン（右下）を押すと、その裏でゲームが始まってしまった
- 設定はゲームの中のメニューにしかなく、始める前に音や言語を変えられなかった（言語だけはタイトルに切替があった）

## 2. 仕様

### 2.1 並び

```
ロゴ・版・ひとこと
[ つづきから（2021 年 4 月 2 週・工房 Lv.3） ]   ← セーブがあるときだけ。いちばん上で強調
[ はじめから ]                                  ← セーブがないときはこれを強調
[ ⏱ RTA で始める ]                             ← 共通基盤の SDK があるときだけ（SPEC-003）
[ ⚙ 設定 ] [ ? 遊び方 ] [ 🏆 ランキング ]       ← 小さめのボタンを 1 行に
© bearko / unofficial fan project
```

- **ボタンを押したときだけ**画面が変わる。タイトルの背景を押しても何も起きない（「PRESS TO START」と、画面全体のクリック・キーの判定を外す）
- 「はじめから」：セーブがあれば確認（SPEC-002 のダイアログ）、なければすぐ始まる
- 言語の切替はタイトルから外し、**設定**に入れる（設定にはもともと言語がある）

### 2.2 タイトルの設定

- 「⚙ 設定」で、ゲームの中の設定（メニュー →「設定」）と**同じ項目**をダイアログで出す：BGM・効果音（ON/OFF と音量）・演出を減らす・言語・アイコン（共通基盤）
- 「時間 2 倍速」は出さない（セーブごとの設定で、始める前には決まっていないため）
- 部品は 1 つだけ持ち、ダイアログを開くあいだだけタイトルのダイアログへ移し、閉じたら戻す（2 つ作ると食い違う）
- `role="dialog"`・`aria-modal`・Esc と「閉じる」で閉じる。タイトルでは時間がまだ動いていないので、`pauseTime` は呼ばない

### 2.3 遊び方

- 「? 遊び方」で、ゲームの中の ? と同じヘルプ（SPEC-007）を出す。タイトルの上に出るよう、重なりの順番（z-index）をタイトルより上にする

## 3. 受け入れ基準

- [ ] セーブあり／なしのどちらでも、始め方がボタンだけになっている
- [ ] タイトルの背景・全体チャットのアイコンを押してもゲームが始まらない
- [ ] タイトルの設定で変えた音・言語が、始めたあとのゲームの設定と同じになっている
- [ ] 設定・遊び方・ランキングを閉じるとタイトルに戻る
- [ ] 360×640 〜 PC で重ならない

## 4. テスト

- Playwright：セーブあり／なしで、背景・右下の隅を押しても始まらないこと、「はじめから」で始まること、タイトルの設定で言語と BGM を変えてゲームのメニューの設定に同じ値が出ること、遊び方・設定の開閉、5 つの画面サイズで要素が重ならないこと
